# Kuntech 静态宣传页

这是一个静态宣传页面，入口为 `index.html`，样式和脚本内嵌，图片资源位于仓库根目录及 `assets/`。

## 本地预览

在仓库目录运行：

```sh
python3 -m http.server 8000
```

然后浏览器访问 `http://localhost:8000/`。也可直接打开 `index.html` 预览。

## 更新与发布

按需编辑页面和资源文件；更新后在本地检查页面及链接，再将经审核的文件发布到现有静态站点托管环境。发布流程和目标环境由项目负责人确认，本仓库不包含部署配置。
